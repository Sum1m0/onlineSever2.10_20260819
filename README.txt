在线客服助理 V2.10 HTML代码包

打开方式：
1. 解压压缩包；
2. 进入“在线客服助理_V2.10”文件夹；
3. 双击 index.html；
4. 建议使用 Chrome 或 Edge 浏览器，并将页面缩放保持为100%。

请勿单独移动 index.html，需保持 index.html 与 assets 文件夹的相对位置。

主要操作：
- 坐席填写回复并点击“发送”后，页面自动出现客户下一条消息；
- 客户消息出现后，自动触发思考状态、话术刷新、历史留存和实时小结更新；
- 点击“切换场景”，在流量争议和费用争议之间切换；
- 页面调整为左侧会话、右侧在线客服助理的两栏结构；
- 流程导航压缩在右栏顶部，不再单独占用一栏；
- 话术推荐区域默认只完整展示一条最新推荐；
- 历史推荐保留在同一滚动区域上方，必须向上滚动才能查看；
- 右侧采用四行固定网格布局，推荐记录增加时仅在推荐区域内部滚动；
- 实时会话小结固定在右栏底部，不会再被推荐区域挤出页面；
- 点击历史推荐后会明确标识“正在回看某时的历史推荐记录”；
- 每条推荐均与对应的业务办理入口成组展示；
- 实时会话小结始终反映当前完整对话，不随历史推荐切换；
- 右侧区域采用窄栏布局，流程导航压缩为一排1—5短步骤；
- 已完成的流程步骤支持点击回退，未完成步骤不可直接跳转；
- 点击“复制”或“填入输入框”使用当前选中的推荐话术；
- 话术进入左侧输入框后，由坐席修改并发送。
- 中间区域展示当前场景对应的业务办理卡片；
- 点击“进入办理”后，顶部新增“业务办理页面”页签并自动打开模拟业务系统；
- 点击“智能客服”页签或办理页中的“返回客服会话”，可返回原会话且状态不丢失；
- 在线质检逐句检查坐席文字回复，命中问题时在对应回复下方提示；
- 页面内置一条违规回复示例，坐席消息下方直接展示红色质检提醒框；
- 会话过程中质检总结果显示“质检中”，点击“结束会话”后生成质检总结果及问题汇总。
